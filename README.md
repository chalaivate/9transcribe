# 9Transcribe

โปรแกรมพิมพ์ด้วยเสียงสำหรับ Windows — กดคีย์ลัด พูด แล้วข้อความจะถูกพิมพ์ลงตรงตำแหน่งเคอร์เซอร์ในโปรแกรมที่กำลังใช้งานอยู่ ไม่ว่าจะเป็น Word, Excel, LINE, Chrome หรือช่องแชทใด ๆ

ออกแบบมาสำหรับ **ภาษาไทยปนภาษาอังกฤษ** โดยเฉพาะ ถอดเสียงด้วยโมเดล `gpt-4o-transcribe` ของ OpenAI

## ความสามารถ

- **กดค้างเพื่อพูด** — กด `Right Ctrl` ค้างไว้ พูด แล้วปล่อย ข้อความจะถูกพิมพ์ให้ทันที
- **กดเพื่อเริ่ม/หยุด** — กด `F8` หนึ่งครั้งเพื่อเริ่มอัด แล้วกด `F8` อีกครั้งเพื่อหยุด (หรือ `Esc` เพื่อยกเลิก) จะคิดนานแค่ไหนก่อนพูดก็ได้ ไม่ตัดจบเอง
- **พิมพ์ทีละประโยคระหว่างพูด** — พูดจบประโยคแล้วเว้นจังหวะสักครู่ ประโยคนั้นจะถูกพิมพ์ออกมาทันทีโดยไม่ต้องหยุดอัด แล้วพูดประโยคถัดไปต่อได้เลย ประโยคจะเรียงตามที่พูดเสมอ
- **พูดยาวไม่หยุดก็มีข้อความขึ้น** — ถ้าพูดต่อเนื่องนาน ๆ โปรแกรมจะยอมตัดที่ช่วงเว้นสั้น ๆ หรือจุดที่เสียงเบาที่สุด แล้วส่งไปถอดเป็นช่วง ๆ (ค่าเริ่มต้นทุกไม่เกิน 10 วินาที ปรับได้) ข้อความเหนือเส้นจะต่อกันแบบคำบรรยายสด และมีจุดเรืองกะพริบระหว่างกำลังถอด
- **คำศัพท์เฉพาะ** — ใส่ชื่อบริษัท ชื่อสินค้า หรือศัพท์เทคนิคไว้ล่วงหน้า เพื่อให้ถอดเสียงได้ตรงตามที่ต้องการ
- **แก้คำอัตโนมัติ** — ตั้งกฎ ค้นหา → แทนที่ สำหรับคำที่มักถอดผิดซ้ำ ๆ
- **แถบสถานะบนเส้นอ้างอิง** — ขณะฟังจะมีแท็บกระจกใสอยู่กึ่งกลางจอใต้เส้นอ้างอิง (ค่าเริ่มต้น 90% จากขอบบน ปรับได้) ในแท็บมีจุดแดงกะพริบ คลื่นเสียง และเวลาที่อัดไปแล้ว ส่วนข้อความที่ถอดได้จะลอยอยู่เหนือเส้นและค่อย ๆ โผล่ทีละคำ
- **คลื่นเสียง Neon Cyber** — เส้นโค้งเรืองแสง 3 เส้นโทนฟ้า cyan → น้ำเงินไฟฟ้า → ม่วง → แมเจนต้า สีไหลไปตามเส้น เร่งความเร็วและพองตัวตามเสียงจริง มีประกายไฟกระเด็นจากยอดคลื่นตอนพูดดัง และขอบแท็บเรืองแสงตามจังหวะเสียง
- **ปรับข้อความที่ถอดได้** — เลือกแสดง/ซ่อน พื้นหลังใสหรือทึบ สีพื้นหลัง สีตัวอักษร และขนาดตัวอักษร พร้อมตัวอย่างสดในหน้าตั้งค่า
- **หน้าตั้งค่าสไตล์ Windows 11** — เมนูด้านข้าง การ์ดตั้งค่า สวิตช์เปิด/ปิด รองรับโหมดมืด และพื้นหลัง Mica บน Windows 11
- **ทำงานอยู่ใน System Tray** — เปิดทิ้งไว้ได้ตลอด ไม่เกะกะ

## เริ่มใช้งาน

1. ดาวน์โหลดจากหน้า [Releases](../../releases) เลือกรุ่นใดรุ่นหนึ่ง:

   | รุ่น | ขนาดไฟล์ | ใช้หน่วยความจำ | ต้องติดตั้งอะไรก่อนไหม |
   |---|---|---|---|
   | **Lite** (`9Transcribe-Lite.exe`) | ~3 MB | น้อยที่สุด | ต้องมี [.NET Desktop Runtime 10 (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) — ถ้ายังไม่มี Windows จะเด้งหน้าดาวน์โหลดให้เอง ติดตั้งครั้งเดียวใช้ได้ตลอด |
   | **Portable** (`9Transcribe-Portable.exe`) | ~150 MB (ดาวน์โหลดแบบ zip ~65 MB) | น้อย | ไม่ต้อง — มี .NET อยู่ในตัว เปิดได้ทันทีทุกเครื่อง |

2. Windows จะขึ้นเตือน SmartScreen เพราะไฟล์ยังไม่ได้เซ็นใบรับรอง ให้กด **More info → Run anyway**
3. เปิดโปรแกรม แล้วคลิกไอคอนใน System Tray → **การตั้งค่า**
4. ใส่ **OpenAI API Key** (สร้างได้ที่ [platform.openai.com/api-keys](https://platform.openai.com/api-keys)) แล้วกด **ทดสอบการเชื่อมต่อ**
5. ลองที่แท็บ **ทดสอบ** เพื่อเช็กไมโครโฟนและดูผลการถอดเสียง

คีย์จะถูกเข้ารหัสด้วย Windows DPAPI เก็บไว้ที่ `%APPDATA%\9Transcribe\settings.json` — เครื่องอื่นหรือผู้ใช้อื่นเปิดอ่านไม่ได้

## หน่วยความจำ

รุ่นก่อน v0.5 ใช้หน่วยความจำมาก เพราะไฟล์ .exe ถูกบีบอัด และต้องแตกไฟล์ทั้งหมดลงหน่วยความจำทุกครั้งที่เปิด รุ่นนี้เลิกบีบอัดแล้ว ผลวัดบนเครื่อง CI ตอนเปิดทิ้งไว้ใน Tray 20 วินาที:

| รุ่น | ขนาดไฟล์ | หน่วยความจำที่จองไว้ (Private bytes) |
|---|---|---|
| Portable แบบเดิม (บีบอัด) | 67 MB | ~90 MB |
| Portable v0.5 | 150 MB | ~26 MB |
| Lite v0.5 | 3 MB | ~26 MB |

คอลัมน์ Memory ใน Task Manager จะต่ำกว่านี้อีกตอนโปรแกรมว่าง (บนเครื่อง CI ราว 2–3 MB) เพราะโปรแกรมคืนหน้าหน่วยความจำให้ Windows หลังเปิด 10 วินาทีและหลังปิดหน้าตั้งค่า ระหว่างใช้งานตัวเลขจะขึ้นกลับมา ซึ่งเป็นเรื่องปกติ

หน้าตั้งค่าถูกปิดและคืนหน่วยความจำทุกครั้งที่ปิดหน้าต่าง (เดิมซ่อนค้างไว้) และบัฟเฟอร์เสียงจะทิ้งส่วนที่ส่งไปถอดแล้ว พูดนานแค่ไหนก็ใช้หน่วยความจำเท่าเดิม ตัวเลขบนเครื่องจริงจะต่างจากตารางตามการ์ดจอและไดรเวอร์ — สคริปต์ `tools/measure-memory.ps1` ใช้วัดบนเครื่องตัวเองได้

## ค่าใช้จ่าย

คิดตามการใช้งานจริงของ OpenAI ตามความยาวเสียงที่ส่งไป (`gpt-4o-transcribe` ประมาณ $0.006 ต่อนาที) เลือกโมเดลที่ถูกลงได้ในหน้าตั้งค่า

## ความเป็นส่วนตัว

- ข้อความที่ถอดได้เก็บไว้ในหน่วยความจำเท่านั้น หายเมื่อปิดโปรแกรม (เปิด "บันทึกประวัติข้อความลงดิสก์" ในแท็บทั่วไปได้ถ้าต้องการ)
- ตอนวางข้อความผ่านคลิปบอร์ด โปรแกรมจะกันข้อความออกจาก **ประวัติคลิปบอร์ดของ Windows (Win+V)** และการซิงก์ขึ้นคลาวด์ ข้อความที่พูดจึงไม่ค้างอยู่ในระบบ
- ไฟล์เสียงถูกส่งไป OpenAI เพื่อถอดเสียงเท่านั้น และไม่ถูกเก็บไว้บนเครื่อง

## ข้อจำกัดที่ควรทราบ

| เรื่อง | รายละเอียด |
|---|---|
| โปรแกรมที่เปิดแบบ Administrator | Windows ไม่ยอมให้โปรแกรมสิทธิ์ปกติพิมพ์ใส่ ในกรณีนี้ข้อความจะถูกคัดลอกไว้ให้กด `Ctrl+V` เอง หรือสั่ง "เริ่มใหม่แบบผู้ดูแลระบบ" จากเมนู Tray |
| หน้าจอ UAC / หน้าล็อกเครื่อง | คีย์ลัดไม่ทำงานบนหน้าจอเหล่านี้ (เป็นข้อจำกัดของ Windows) |
| เกมแบบเต็มจอจริง (exclusive fullscreen) | แถบสถานะจะไม่แสดง — โหมด borderless ใช้ได้ปกติ |
| PuTTY / RDP / VM Console | โปรแกรมเหล่านี้รับข้อความคนละแบบ โปรแกรมจะสลับวิธีพิมพ์ให้อัตโนมัติตามชื่อโปรแกรม (แก้รายชื่อได้ในไฟล์ `settings.json`) |

## ถ้ากดค้างแล้วยังมีปัญหา

เปิดโฟลเดอร์ log จากเมนู Tray แล้วดูว่ามีบรรทัดเหล่านี้ซ้ำ ๆ ระหว่างที่กดค้างอยู่หรือไม่ — เป็นตัวบอกว่าโปรแกรมอื่นในเครื่อง (IME, ตัวรีแมปคีย์, ซอฟต์แวร์คีย์บอร์ดของผู้ผลิต) กำลังแย่งอ่านปุ่มนั้นไป ลองเปลี่ยนคีย์ลัดเป็นปุ่มอื่นในแท็บคีย์ลัด

| ข้อความใน log | ความหมาย |
|---|---|
| `key-up never arrived` | ระบบไม่บันทึกว่าปุ่มถูกกดค้าง ทั้งที่ยังกดอยู่ |
| `force-released after` | กดค้างนานเกินค่าสูงสุดที่ตั้งไว้ |

## สำหรับนักพัฒนา

ต้องใช้ **.NET 10 SDK** บน Windows

```powershell
dotnet build 9Transcribe.sln -c Release
dotnet test  tests/9Transcribe.Tests/9Transcribe.Tests.csproj -c Release

# รุ่น Portable: มี .NET ในตัว (อย่าเปิด EnableCompressionInSingleFile — กินหน่วยความจำเพิ่ม ~80 MB)
dotnet publish src/9Transcribe/9Transcribe.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true -o publish/portable

# รุ่น Lite: ใช้ .NET Desktop Runtime ที่ติดตั้งในเครื่อง
dotnet publish src/9Transcribe/9Transcribe.csproj -c Release -r win-x64 `
  --self-contained false -p:PublishSingleFile=true -o publish/lite

# วัดหน่วยความจำตอนเปิดทิ้งไว้ใน Tray
pwsh tools/measure-memory.ps1 -Label Lite -Path publish/lite/9Transcribe.exe
```

โครงสร้างโค้ด:

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `Audio/` | อัดเสียง 16 kHz mono ผ่าน NAudio, ตรวจจับความเงียบ (VAD), ตัดประโยคระหว่างอัด และตัดช่วงพูดยาว (`SegmentPacing`) |
| `Hotkeys/` | คีย์ลัดทั่วระบบด้วย low-level keyboard hook (รองรับการกดค้าง) |
| `Injection/` | วางข้อความผ่านคลิปบอร์ดหรือจำลองการพิมพ์ Unicode |
| `Api/` | เรียก OpenAI `/v1/audio/transcriptions` |
| `Overlay/` | แถบสถานะแบบลอยที่ไม่แย่งโฟกัส, คลื่น neon (`WaveMath`) และข้อความแบบคำบรรยายสด (`RollingTranscript`) |
| `UI/`, `Tray/` | หน้าตั้งค่าภาษาไทย และไอคอน System Tray |
| `Settings/` | โครงสร้างค่าตั้งและการเข้ารหัส API Key |

ไอคอนสร้างจากสคริปต์ `tools/make_icons.py` (Python ล้วน ไม่ต้องลงไลบรารีเพิ่ม) รันใหม่เมื่อแก้สีหรือรูปทรง
