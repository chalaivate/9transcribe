# 9Transcribe

โปรแกรมพิมพ์ด้วยเสียงสำหรับ Windows — กดคีย์ลัด พูด แล้วข้อความจะถูกพิมพ์ลงตรงตำแหน่งเคอร์เซอร์ในโปรแกรมที่กำลังใช้งานอยู่ ไม่ว่าจะเป็น Word, Excel, LINE, Chrome หรือช่องแชทใด ๆ

ออกแบบมาสำหรับ **ภาษาไทยปนภาษาอังกฤษ** โดยเฉพาะ ถอดเสียงด้วยโมเดล `gpt-4o-transcribe` ของ OpenAI

## ความสามารถ

- **กดค้างเพื่อพูด** — กด `Right Ctrl` ค้างไว้ พูด แล้วปล่อย ข้อความจะถูกพิมพ์ให้ทันที
- **กดเพื่อเริ่ม/หยุด** — กด `F8` หนึ่งครั้งเพื่อเริ่มอัด โปรแกรมจะหยุดเองเมื่อเงียบ (หรือกด `F8` ซ้ำ / กด `Esc` เพื่อยกเลิก)
- **คำศัพท์เฉพาะ** — ใส่ชื่อบริษัท ชื่อสินค้า หรือศัพท์เทคนิคไว้ล่วงหน้า เพื่อให้ถอดเสียงได้ตรงตามที่ต้องการ
- **แก้คำอัตโนมัติ** — ตั้งกฎ ค้นหา → แทนที่ สำหรับคำที่มักถอดผิดซ้ำ ๆ
- **แถบสถานะเล็ก ๆ** — แสดงว่ากำลังฟังหรือกำลังถอดเสียง พร้อมพรีวิวข้อความตัวใหญ่เมื่อเสร็จ เลือกวางได้ 8 ตำแหน่งบนจอ
- **ทำงานอยู่ใน System Tray** — เปิดทิ้งไว้ได้ตลอด ไม่เกะกะ

## เริ่มใช้งาน

1. ดาวน์โหลด `9Transcribe.exe` จากหน้า [Releases](../../releases) — เป็นไฟล์เดียวจบ ไม่ต้องติดตั้ง
2. Windows จะขึ้นเตือน SmartScreen เพราะไฟล์ยังไม่ได้เซ็นใบรับรอง ให้กด **More info → Run anyway**
3. เปิดโปรแกรม แล้วคลิกไอคอนใน System Tray → **การตั้งค่า**
4. ใส่ **OpenAI API Key** (สร้างได้ที่ [platform.openai.com/api-keys](https://platform.openai.com/api-keys)) แล้วกด **ทดสอบการเชื่อมต่อ**
5. ลองที่แท็บ **ทดสอบ** เพื่อเช็กไมโครโฟนและดูผลการถอดเสียง

คีย์จะถูกเข้ารหัสด้วย Windows DPAPI เก็บไว้ที่ `%APPDATA%\9Transcribe\settings.json` — เครื่องอื่นหรือผู้ใช้อื่นเปิดอ่านไม่ได้

## ค่าใช้จ่าย

คิดตามการใช้งานจริงของ OpenAI ตามความยาวเสียงที่ส่งไป (`gpt-4o-transcribe` ประมาณ $0.006 ต่อนาที) เลือกโมเดลที่ถูกลงได้ในหน้าตั้งค่า

## ความเป็นส่วนตัว

- ข้อความที่ถอดได้เก็บไว้ในหน่วยความจำเท่านั้น ไม่บันทึกลงดิสก์ (เปิดใช้ได้เองในหน้าตั้งค่า)
- ตอนวางข้อความผ่านคลิปบอร์ด โปรแกรมจะกันข้อความออกจาก **ประวัติคลิปบอร์ดของ Windows (Win+V)** และการซิงก์ขึ้นคลาวด์ ข้อความที่พูดจึงไม่ค้างอยู่ในระบบ
- ไฟล์เสียงถูกส่งไป OpenAI เพื่อถอดเสียงเท่านั้น และไม่ถูกเก็บไว้บนเครื่อง

## ข้อจำกัดที่ควรทราบ

| เรื่อง | รายละเอียด |
|---|---|
| โปรแกรมที่เปิดแบบ Administrator | Windows ไม่ยอมให้โปรแกรมสิทธิ์ปกติพิมพ์ใส่ ในกรณีนี้ข้อความจะถูกคัดลอกไว้ให้กด `Ctrl+V` เอง หรือสั่ง "เริ่มใหม่แบบผู้ดูแลระบบ" จากเมนู Tray |
| หน้าจอ UAC / หน้าล็อกเครื่อง | คีย์ลัดไม่ทำงานบนหน้าจอเหล่านี้ (เป็นข้อจำกัดของ Windows) |
| เกมแบบเต็มจอจริง (exclusive fullscreen) | แถบสถานะจะไม่แสดง — โหมด borderless ใช้ได้ปกติ |
| PuTTY / RDP / VM Console | บางโปรแกรมรับข้อความได้ไม่ครบ ปรับ "วิธีพิมพ์ข้อความ" ต่อโปรแกรมได้ในหน้าตั้งค่า |

## สำหรับนักพัฒนา

ต้องใช้ **.NET 8 SDK** บน Windows

```powershell
dotnet build 9Transcribe.sln -c Release
dotnet test  tests/9Transcribe.Tests/9Transcribe.Tests.csproj -c Release

# สร้างไฟล์ .exe เดียวแบบพกพา
dotnet publish src/9Transcribe/9Transcribe.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true -o publish
```

โครงสร้างโค้ด:

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `Audio/` | อัดเสียง 16 kHz mono ผ่าน NAudio และตรวจจับความเงียบ (VAD) |
| `Hotkeys/` | คีย์ลัดทั่วระบบด้วย low-level keyboard hook (รองรับการกดค้าง) |
| `Injection/` | วางข้อความผ่านคลิปบอร์ดหรือจำลองการพิมพ์ Unicode |
| `Api/` | เรียก OpenAI `/v1/audio/transcriptions` |
| `Overlay/` | แถบสถานะแบบลอยที่ไม่แย่งโฟกัส |
| `UI/`, `Tray/` | หน้าตั้งค่าภาษาไทย และไอคอน System Tray |
| `Settings/` | โครงสร้างค่าตั้งและการเข้ารหัส API Key |

ไอคอนสร้างจากสคริปต์ `tools/make_icons.py` (Python ล้วน ไม่ต้องลงไลบรารีเพิ่ม) รันใหม่เมื่อแก้สีหรือรูปทรง
